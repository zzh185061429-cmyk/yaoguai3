# 燕京地点分级文档

> 幻璃镜项目地点数据结构说明
>
> 共 **471** 个常驻地点 + **22** 个复用场景模板

---

## 一、设计理念

本项目是一个志怪探案类型的游戏，地点系统需满足两种需求：

1. **常驻地点**：固定在燕京地图上的某个位置，剧情中随时可以回去
2. **复用场景模板**：不固定在地图某个位置，由特定剧情触发后才出现，且可以"套"到不同区域使用

例如"荒庙"这个场景——这次案件在东城某条巷子里触发，下次案件可能在西山山道上触发，场景图复用但归属不同。这类场景不需要在地图树里写死位置，而是由 AI 在剧本中通过 `[scene:东城/荒庙]` 或 `[scene:荒庙]` 来调用。

---

## 二、数据结构

### 常驻地点树 (`RESIDENT_LOCATIONS`)

- **key 格式**：`区域/分区/.../场景名`
- **示例**：`内城/北城/07肃王府/肃王府大门前庭`
- **每个条目**：名称、完整路径、类型(室内/室外)、图片变体及URL

### 复用场景模板池 (`TEMPLATE_LOCATIONS`)

- **key 格式**：`场景名`（无路径前缀）
- **示例**：`荒庙`、`祠堂`、`草户农家院`
- **每个条目**：名称、类型(室内/室外)、图片变体及URL

### 查找逻辑

```
getLocationImage(locationKey, variant)
  1. 先在常驻地点中精确匹配 locationKey
  2. 找不到则取路径最后一段，在模板池中查找
  3. 都找不到返回 undefined
```

AI 输出时可以写完整路径，也可以只写短名：

```
[scene:东城/01商贸/荒庙]    ← 指定区域的荒庙（先查常驻树，再查模板池）
[scene:西山/荒庙]           ← 西山的荒庙（同上）
[scene:荒庙]                ← 不指定区域，直接用模板（直接查模板池）
```

## 六、AI 使用指南

### scene 标签

```
[scene:区域/分区/.../场景名]     ← 完整路径，精确匹配
[scene:场景名]                    ← 短名，先查常驻树再查模板池
```

**示例**：
```
[scene:内城/北城/07肃王府/肃王府大门前庭]   ← 精确到肃王府大门前庭
[scene:内城/西城/04勋贵/镇国公府正堂]       ← 精确到镇国公府正堂
[scene:荒庙]                                ← 复用模板，不指定区域
[scene:东城/荒庙]                           ← 复用模板，暗示在东城出现
```

### scene_image 标签

```
<scene_image>区域/分区/.../场景名/天气/时间</scene_image>
```

**示例**：
```
<scene_image>内城/北城/07肃王府/肃王府大门前庭/阴/夜</scene_image>
<scene_image>荒庙/夜</scene_image>
```

### 地点命名规范

AI 输出地点名时应与本文档中的场景名完全一致。常驻地点使用完整路径或短名均可，复用场景直接用短名。
