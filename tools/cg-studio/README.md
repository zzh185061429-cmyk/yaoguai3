# CG Studio — 可复用批量生图工作台

零依赖、无构建的本地批量生图工具。提示词、API、任务清单、输出目录**全部是运行时由你填的数据**——换个项目就是换一份清单，工具本身不含任何业务内容。

## 启动

```bash
cd tools/cg-studio
node server.mjs
# 打开浏览器访问 http://127.0.0.1:17891（端口被占用时: PORT=18000 node server.mjs）
```

要求 Node 18+（本机为 v24，直接可用）。服务器只绑定 127.0.0.1，不对外网开放。

## 两种模式

顶部切换，选择自动记住：

- **🖼 通用生图**：卡片式快速出图。每张卡片 = 提示词 + 可选参考图导入 + 生成按钮，人像、场景、道具单张直出，可随时加卡片；尺寸 / 质量 / 模型在设置区统一调，结果自动进画廊与输出目录。
- **🗺 地点 CG**：面向地点背景矩阵的批量流水线。「导入提示词设计」可粘贴整份设计文档一键填入全局风格与全部布局指令；「AI 提示词工坊」（中文地点描述 → 英文提示词，转写结果以"英文译名 (中文原名)"开头，手动使用）、「批量展开」（室内 = 昼/夜；室外 = 晴/阴/雪 × 昼/夜；描述可写中文原样发送；**地点名写进提示词开头**——模型只看提示词不看文件名）→ 任务表 → 预检 → 批量执行。展开时全局前缀与地点主体直接烘进每行提示词，行内即最终发送内容。

## 核心概念

**任务表 = 唯一真相。** 每行 = 一张图：

| 列 | 说明 |
|---|---|
| 文件名 | 最终保存的文件名（自动统一 `.png` 扩展；不能重名；`manifest.json` 是保留名） |
| 参考图 | **留空** = 文生图锚点；**填另一行的文件名** = 用那张图当参考派生（edits 接口）；**填外部路径** = 导入已有图当参考 |
| 提示词 | 这一张自己的提示词。批量展开烘成：全局前缀 + 地点名:描述 + 布局指令，行内即最终发送内容，行内「预览提示词」直接显示 |

**全局风格前缀**：一段所有图共用的风格提示词（开关可关），省去每行复制。

## 防参考错误机制

- 预检时每行的参考图会解析为：`锚点` / `参考任务(第N批)` / `参考已有图` / `参考缺失✗`（缺失则该行锁死不执行）
- 依赖任务自动拓扑排序：锚点永远先于派生执行；循环依赖直接报错
- 依赖任务失败时，下游派生任务**连锁跳过**并标注原因，不会拿错图
- 每张图在输出目录的 `manifest.json` 里记录完整来源（提示词、参考、用量、时间），画廊中点图可溯源

## 断点续跑与重生成

- 再次「开始」时，**已生成**和**文件已存在**的任务自动跳过（保护手动放置的同名文件）
- 画廊中「重生成」= 删除该文件与记录后强制重跑该行。每次生图请求默认附加随机变体标记（防缓存，可在高级设置关闭）——中转站对完全相同的请求可能返回同一张缓存图，导致删掉重跑还是一模一样的图
- 中断（停止/关机）后重新打开，配置和进度都在：配置存 `data/config.json`，进度存输出目录的 `manifest.json`

## 典型工作流（地点 CG 矩阵）

1. **设置**：填 API 地址 / Key → 模型输入框点开下拉选模型（`gpt-image-2`，⟳ 可重新拉取列表）→ 点尺寸比例芯片（16:9 / 3:2 / 1:1 / 2:3 / 自定义）→ 测试连接；浏览选择输出目录
2. **全局前缀**：粘贴全局风格提示词，启用
3. **任务表**：每个地点一行锚点（晴-昼，参考图留空）+ N 行变体（晴-夜/阴-昼/阴-夜/雪-昼/雪-夜，参考图填锚点文件名）。可在 Excel 编好后「从 Excel 粘贴导入」
4. **预检** → 确认无红标 → **开始**，看进度和日志
5. **画廊**审阅：不满意的单张重生成；全部满意后图片已在输出目录，直接取用

## 目录说明

```
tools/cg-studio/
  server.mjs      # 服务器：API 代理、任务队列、拓扑排序、manifest
  public/         # 前端单页（原生 JS）
  data/           # 运行数据：config.json（含 API Key，已 gitignore）
  _probe/         # 开发期接口探测与回归脚本（已 gitignore）
```

`data/` 与 `_probe/` 均已加入仓库 `.gitignore`，**API Key 不会入库**。

## 图床上传（PostImages）

生成完成后，在「图床上传」面板把图片传到你的 PostImages 账号并自动生成链接文档：

1. **API Key（一次性）**：浏览器登录 postimages.org → 打开 `postimages.org/login/api` → 生成 Key，粘贴到面板里（只存本机 `data/config.json`）
2. **图库映射**：点「扫描输出目录」，每个顶层文件夹一行；在对应行填入图库链接或 ID（在 postimg 网页端建好图库后，把图库网址整条贴进来即可，自动提取 ID；留空 = 不进图库，传到账号默认位置）
3. **开始上传**：顺序上传（每张间隔 0.8 秒限速 + 失败自动重试 1 次），已上传的重跑自动跳过
4. **自动产出文档**（保存在输出目录根）：
   - `图床链接.txt` — 按你的文件夹结构分组、每张图一条直链的纯文本文档，直接可读

上传协议为社区逆向的官方接口（`api.postimage.org/1/upload`，PicGo 同款），直链从图片页自动解析为 `i.postimg.cc/...` 格式，可直接嵌入角色卡/前端。

## 已知边界

- 输出统一按 `.png` 保存（gpt-image 系返回 PNG）
- **尺寸**：接口接受任意 `宽x高`，但模型按"接近所请求宽高比"出图，像素数由模型内部决定——实测请求 `1920x1080` 返回约 `1672x941`（≈16:9）。宽高比是可靠的，精确分辨率不是
- 文件被手动改名/移动后，manifest 记录会与之脱节（该文件将视为"文件已存在"而跳过，不会被覆盖）
- 花费统计以 token 用量展示（input/output tokens + 张数），换算金额取决于中转站计费规则
