✨ AI 提示词工坊（中文地点描述 → 英文提示词）

用你已配置的中转站 API Key 调用文字模型，把中文地点描述自动转写成英文生图提示词。支持多种通用格式，每行一条，AI 自动识别：

📖 支持的输入格式（点开看示例） 
格式A — 地点名：描述（最通用）
  奉天殿：朝会正殿，金柱礼器，空旷庄严
  午门：五凤楼形制城楼，献俘颁诏

格式B — 地点名, 室内|室外, 描述（完整三列）
  奉天殿, 室内, 朝会正殿金柱礼器
  午门, 室外, 五凤楼形制城楼

格式C — 文件夹/地点名：描述（自动分组）
  前朝大殿/奉天殿：朝会正殿
  前朝门庭/午门：五凤楼形制

格式D — 纯描述（AI 自动起名+判断室内外）
  朝会正殿，金柱礼器，空旷庄严
  五凤楼形制城楼，献俘颁诏

以 # 开头为注释行，会被跳过。
冒号支持中英文（：/:），逗号支持中英文（，/,）。

转写结果自动写入下方「批量展开」的地点清单，可在展开前手动微调。室内/室外由 AI 根据描述自动推断。

📐 批量展开（地点清单 → 变体矩阵）

📥 导入提示词设计（粘贴设计文档，一键填入全局风格与全部布局指令）
识别「全局风格」与 室内/室外 × 晴/阴/雪 × 昼/夜 各段；中文说明行自动忽略，只取英文指令；有内容的天气组自动勾选启用
室内变体 昼 = 锚点（文生图），夜派生自昼
室外变体 晴 / 阴 / 雪 × 昼 / 夜，勾选启用某种天气；第一个启用的昼 = 锚点
室内 → 昼/夜 2 行；室外 → 启用的天气 × 昼/夜。行内提示词 = 全局前缀 + 地点名:描述 + 布局指令，展开时烘进每行即最终发送内容——地点名必须进提示词，模型不看文件名。同名任务行提示词有变化时原位更新，无变化跳过。

📋 任务清单（每行 = 一张图 = 一个文件名）

文件名：最终保存名，可用 文件夹/名称 分组（如 前朝大殿/奉天殿-昼，自动建文件夹，自动统一 .png）　参考图：留空 = 文生图锚点；填另一行的文件名 = 用它派生；填外部路径 = 导入已有图当参考
