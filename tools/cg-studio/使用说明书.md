CG Studio 批量生图工作台 · 使用说明书
══════════════════════════════════════════════════

【这是什么】
一个本地跑的可复用批量生图工具：提示词、API、任务清单、输出位置
全部由你填写，工具只负责编排——批量调度、参考图自动传递、防错、
审阅、上传图床、生成链接文档。

【启动】
双击 启动CG-Studio.bat，浏览器自动打开 http://127.0.0.1:17891
关闭黑窗口 = 停止服务（配置、清单、图片、上传记录全部保留）。
端口被占用时：命令行 set PORT=18000 && node server.mjs

────────────────────────────────────────────────
一、30 秒上手
────────────────────────────────────────────────
0. 顶部选模式：通用生图（卡片快速出图）或 地点 CG（地点矩阵）
1. 设置区：填 API 地址 + Key → 选模型与尺寸 → 测试连接 →
   选输出目录
2. 任务清单：手动加行 / Excel 粘贴 / 批量展开
3. 预检 → 无红标 → 开始批量生成
4. 画廊审阅：单张重生成 / 删除 / 已审隐藏
5. 图床上传：填 Key → 扫描 → 填图库映射 → 上传 → 输出目录里
   自动生成 图床链接.txt

────────────────────────────────────────────────
二、任务清单（地点 CG 模式的批量执行清单）
────────────────────────────────────────────────
每行 = 一张图 = 一个文件名。三列：

文件名  最终保存名。支持 文件夹/名称 分组（可多层，自动建文件夹），
        自动统一 .png 扩展。例：前朝大殿/奉天殿-昼
参考图  四种写法——
        · 留空 = 文生图锚点（这一组的第一张）
        · 填另一行的文件名 = 用那张图派生（自动拓扑排序，锚点先跑）
        · 填外部路径 = 导入已有图当参考
        · 点 📁 按钮 = 上传本机图片当参考（保存到 _uploads/ 文件夹）
提示词  这一张自己的描述 + 变体指令

预检会给每行打标：锚点·文生图 / 派生·第N批 / 参考缺失✗
（缺失的行锁死不跑）。循环依赖直接报错。依赖失败时下游连锁跳过。

【防参考错误四规则】
1. 变体只参考本地点的锚点（星形，不建议链式，会累积漂移）
2. 锚点未完成前派生不启动
3. 每张图落盘记录完整来源，画廊点图可溯源
4. 已生成/已存在的文件默认跳过不覆盖；重生成走画廊按钮（显式删除重跑）

【上传参考图】
参考图列右侧有 📁 按钮，点击后选择本机图片（PNG/JPEG/WebP），
自动上传到输出目录的 _uploads/ 子文件夹，并填入参考图列。
上传的图可像其他参考图一样使用——生成时走 edits 接口，基于
这张图派生变体。

【断点续跑】
中断（停止/关机）后重新打开：配置在 data/config.json，
进度在输出目录 manifest.json。再点开始，已完成的自动跳过。

────────────────────────────────────────────────
三、界面与设置
────────────────────────────────────────────────
【两种模式】顶部切换，自动记住上次选择：
  通用生图  卡片式快速出图：每张卡片填提示词、可选导入
            参考图、点生成即出（人像/场景/道具均可）
  地点 CG   地点矩阵批量流水线：AI 提示词工坊 → 批量展开
            → 任务清单 → 预检 → 批量执行

【设置区】
· API 连接：地址填 OpenAI 兼容中转站（含 /v1）+ Key。
  模型输入框点开即出现下拉列表（输入可过滤），点 ⟳ 随时
  重新拉取；「测试连接」也会刷新列表
· 质量档位：low 省钱 / medium 推荐 / high 最佳 / auto
· 尺寸比例：点芯片选 16:9 / 3:2 / 1:1 / 2:3；不常见比例
  点「自定义」后直接输入 宽x高。模型按所请求的宽高比出图，
  像素数内部决定（实测 1920x1080 → 约 1672x941，≈16:9）
· 输出目录：点「浏览…」选择，图片与 manifest.json 都存这里
· 高级设置（设置区底部折叠）：并发数 / 失败自动重试 / 单张
  超时 / 防缓存变体标记 / 全局风格前缀。全局前缀是一段所有图
  共用的风格描述，开关控制，批量展开时烘进每行提示词；任务行内
  「预览提示词」直接显示最终发送内容
· 防缓存变体标记：中转站可能对完全相同的请求返回同一张缓存图
  （表现为删掉重跑还是一模一样的图）。开启后每次请求在提示词
  末尾附加随机标记，重生成必定重新出图
· 派生机制：edits 接口传参考图，"保持这张图内容，改成夜晚"，
  结构保持非常好

四、快速生成卡片（通用模式）
────────────────────────────────────────────────
每张卡片独立出图：
  · 提示词：这张图的描述（人像/场景/道具均可）
  · 文件名：可选；留空自动按时间命名（存 快速生成/ 子

  · 📁 参考图：可选，上传本机图片，生成时基于它派生

    显示结果，点图可放大；图片同时进入画廊和输出目录
  · 「+ 加一张卡片」随时扩展，卡片内容自动保存

────────────────────────────────────────────────
五、AI 提示词工坊（中文描述 → 英文提示词）
────────────────────────────────────────────────
用你已配置的中转站 API Key（GPT 账号）调用文字模型，
把中文地点描述自动转写成英文生图提示词。

【为什么不用单独开 ChatGPT】
生图用的 API Key 本身就能调文字模型接口（/chat/completions），
所以不需要额外开网页或兵账号——直接在工具里点一下
就把全部地点描述批量转写成英文提示词。

【支持的通用输入格式】（每行一条，自动识别）
格式A — 地点名：描述（最通用）
  奉天殿：朝会正殿，金柱礼器，空旷庄严
  午门：五凤楼形制城楼，献俘颁诏

格式B — 地点名, 室内|室外, 描述（完整三列）
  奉天殿, 室内, 朝会正殿金柱礼器
  午门, 室外, 五凤楼形制城楼

格式C — 文件夹/地点名：描述（自动分组）
  前朝大殿/奉天殿：朝会正殿
  前朝门庭/午门：五凤楼形制

格式D — 纯描述（AI 自动起名+判断室内外）
  朝会正殿，金柱礼器，空旷庄严
  五凤楼形制城楼，献俘颁诏

以 # 开头为注释行，会被跳过。
中英文冒号（：/:）、逗号（，/,）都支持。

【输出风格】
  自然语言描述风：流畅的英文场景描述句（工具默认）

【室内/室外判断】
AI 根据描述自动判断：殿/堂/阁/斋/房/院落室内 = indoor；
门/墙/街/桥/庭/广场/苑 = outdoor。结果直接写入
「批量展开」的地点清单，可在展开前手动微调。

【文字模型】默认 gpt-5-6-mini，可改为你的中转站
支持的任意文字模型（如 gpt-4o-mini 等更便宜的型号）。

────────────────────────────────────────────────
六、AI 对话（和 GPT 聊天写提示词）
────────────────────────────────────────────────
直接在工具里和文字模型聊天，像用 ChatGPT 一样来回讨论、
迭代修改提示词。不需要额外开网页或切换账号——
用的就是你在设置区填的中转站 API Key。

【基本用法】
  · 在输入框里写你的需求，Ctrl+Enter 或点「发送」
  · AI 会流式回复（边写边显示），你可以继续追问或要求修改
  · 满意了点下方的导出按钮

【导出按钮】
  导入最后一条到任务表  从 AI 最后回复中提取英文提示词，
                          按「地点名: 提示词」格式解析为任务行
  导入到地点清单        提取的提示词写入「批量展开」的地点清单，
                          可继续批量展开
  导入到全局前缀        提取的文本写入「全局风格前缀」输入框

【典型对话流程】
  你：帮我写一个明代奉天殿的英文提示词，要有金柱和礼器
  AI：（给出英文提示词，可能用代码块包裹）
  你：太写实了，改成更偏二次元动漫风格
  AI：（给出修改后的版本）
  你：很好，再帮我加上夜景版本
  AI：（给出白天和夜晚两个版本）
  → 点「导入最后一条到任务表」→ 自动解析为任务行

【说明】
  · 对话历史保存在内存中，清空对话或刷新页面后重置
  · 文字模型默认与「AI 提示词工坊」共用（api-textModel 字段）
  · 如果中转站不支持流式（stream），会回退为一次性返回
  · 代码块（``` 包围的部分）在气泡中会高亮显示为绿色，
    便于辨认最终提示词

────────────────────────────────────────────────
七、批量展开（地点 CG 模式）
────────────────────────────────────────────────
【导入提示词设计】面板顶部可粘贴整份设计文档一键填入：
  · 「全局风格」段 → 全局风格前缀（中文说明行自动忽略，只取英文）
  · 「室内版布局指令（昼/夜）」「室外版布局指令（晴/阴/雪天组 - 昼/夜）」
    → 对应变体框；有内容的天气组自动勾选启用

变体是固定结构：
  室内变体  昼（锚点，文生图）/ 夜（派生自昼）两个框
  室外变体  晴/阴/雪 三组，每组 昼+夜 两个框；勾选框
            启停某种天气，第一个启用的昼 = 锚点

地点清单每行：文件夹/地点名, 室内|室外, 场景描述
  · 描述可写中文（gpt-image 可直接理解中文，原样发送不转译）
  · 描述可含逗号（只切前两刀）；# 开头 = 注释
  · 室内地点 → 昼/夜 2 行；室外地点 → 启用的天气 × 昼/夜
  · 行内提示词 = 全局前缀 + 地点名:描述 + 布局指令，展开时直接
    烘进每行，行内内容就是最终发给模型的内容
  · 地点名会写进提示词开头——模型只看提示词不看文件名，地点名
    不进提示词就画不出这个地点（如"奉天殿"三个字必须出现在
    提示词里，模型才认识这座地标建筑）
  · 同名任务行提示词有变化时原位更新（改描述/改指令后重新展开
    即可刷新），无变化跳过；展开后是普通表格行可手改

【AI 提示词工坊 + 批量展开的协作流程】
  1. 在 AI 提示词工坊粘贴中文地点描述（任意格式）
  2. 点「AI 转写英文提示词」 → AI 批量转写并写入地点清单
  3. 在批量展开里检查/微调地点清单
  4. 点「展开到任务表」 → 自动生成全部任务行
  5. 预检 → 批量生成
  从中文描述到全部图片出来，全程在工具内完成，
  不需要手动开 ChatGPT 写提示词。

────────────────────────────────────────────────
八、画廊管理（图多了不乱）
────────────────────────────────────────────────
  ✔ 已审（单张）   从列表隐藏这一张（不删文件）
  ✔ 全部已审，清空显示   一键把当前所有图标记已审，列表清空
  显示全部（重置已审）    恢复显示所有图
  已审状态存在浏览器里，文件与 manifest 完全不动；
  任务表也有「隐藏已完成/已存在的行」勾选框，同理只影响显示。
  重生成 = 删除文件+记录后强制重跑（走当前引擎）。每次请求
  自动附加随机变体标记（防缓存），重生成不会拿到同一张图；
  修改过描述/指令后先重新「展开到任务表」刷新行内提示词，
  再点重生成。

九、白底抠图
────────────────────────────────────────────────
生成的立绘常是纯白背景，画廊区内置一键抠图：

【为什么不会误伤白尾巴/白衣/高光】
算法是"边缘泛洪填充"——只删除与图片边框连通的白色区域。
被角色轮廓包住的白色（白尾巴尖、白衣、鼻尖高光）不连通
边框，绝对不会被动。

【参数】
白底容差  默认 12（≥243 视为白）。白底带浅灰阴影/噪点时
          调大到 20-30；误伤浅色边缘时调小
边缘羽化  默认 1。0=硬边；1-2 会把边缘"半白"像素转成
          渐变透明并做去白合成（消除白毛边），推荐 1

【用法】
单张：卡片上「✂ 抠白底」；批量：「✂ 批量抠图（未抠的全部）」
结果保存为 原名_cut.png（原图保留），已抠的会显示绿色标记，
重抠随时可做。抠完的透明 PNG 会被图床上传一并扫进去传图床。

【边界情况】
· 白色衣袖直接伸出画面外（与边框连通）会被当背景删掉——
  这属于颜色法原理性盲区，重新生成或手动修
· 脚下阴影是灰色（<容差下限）时不会被删；想连阴影一起删
  就调大容差（注意观察预览效果）

十、图床上传（PostImages）
────────────────────────────────────────────────
1. API Key（一次性）：浏览器登录 postimages.org → 打开
   postimages.org/login/api → 生成 Key → 粘贴（只存本机）
2. 图库：在 postimg 网页端先建好图库（每个父地点一个），
   扫描后在对应文件夹行贴图库网址（自动提取ID；留空=不进图库）
3. 上传：顺序+限速+自动重试，已传的重跑跳过
4. 产出：输出目录/图床链接.txt —— 按你的文件夹结构分组、
   每张图一条直链，随时打开都是最新

────────────────────────────────────────────────
十一、常见问题
────────────────────────────────────────────────
Q: 端口被占用？       A: set PORT=18000 && node server.mjs
Q: 换电脑怎么迁移？   A: 整个 tools/cg-studio 文件夹拷走
   （data/config.json 里含全部配置与 Key）
Q: 中转站换地址了？   A: 改设置区的 API 地址，任务清单不动
Q: gpt 出图画风偏写实？ A: 用 medium/high 档
Q: 图片被手动改名？   A: manifest 会脱节，该文件按"已存在"跳过，
   不会被覆盖；要重跑用画廊的重生成
Q: 一次能跑多少张？   A: 无上限，建议一批 ≤100 张方便审阅；
   随时停止，续跑不重复
