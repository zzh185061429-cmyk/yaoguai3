# NAI Studio 使用说明书

一个本地运行的 NovelAI 角色立绘工作台。这份说明书面向使用流程；技术细节看 README.md。

## 一、首次配置（三步）

1. **启动**：双击 `启动NAI-Studio.bat`（或命令行 `node server.mjs`），浏览器打开 http://127.0.0.1:17892
2. **填令牌**：
   - 登录 novelai.net → 账户设置（Account）→ API Keys → 生成持久令牌（`pst-` 开头）
   - 粘贴到「连接与生成参数 → NAI 令牌」输入框 → 点「测试连接」
   - 看到「✔ 已连接（Opus…）」即成功；订阅信息条会显示 Anlas / 会员到期 / V5 用量
   - 令牌只存在本机 data/config.json，不会进 Git。它等于账号钥匙，别截图外发
3. **选输出目录**：点「浏览…」选一个存图文件夹（建议空文件夹，会自动建子目录）

> **连不上 / 挂了梯子也不行？** Node 不走浏览器代理——在「连接与生成参数 → 网络与代理」点 **「检测代理」**：
> 会自动读取系统代理并探测 Clash(7890/7897)/v2rayN(10808/10809) 等常用端口，探测到就给「用 127.0.0.1:端口」一键应用按钮。
> 应用后**重启服务**（关掉窗口重新双击 bat）再测试连接。梯子开 TUN/全局模式则无需任何配置。

## 二、生成参数速查

| 参数 | 建议 | 说明 |
|---|---|---|
| 模型 | nai-diffusion-4-5-full（或 V5） | full 质量最好；Opus 标准尺寸文生图免费 |
| 分辨率 | 832×1216（竖版立绘） | 64 的倍数；≤1024×1024 像素总数才在 Opus 免费档 |
| 步数 | 28 | Opus 免费上限就是 28，超过开始扣 Anlas |
| Scale | 5 | V4.5 默认；提示词服从度 |
| 采样器 | k_euler_ancestral | 立绘常用；动图感强可用 k_dpmpp_2m |
| 噪声调度 | karras | V4.5 默认 |
| UC 预设 | 重型 Heavy | 负面词兜底 |

订阅信息条（页面顶部）实时显示：档位、Anlas 余额、会员到期、V5 用量池（Opus）。每 5 分钟自动刷新，每次生成后也会刷新。

## 三、通用生图（快速出图）

1. 顶部切到「🖼 通用生图」
2. 卡片里填提示词（英文 danbooru 标签；输入时会出现官方标签联想，↑↓ 选、Enter/Tab 插入；画师串收藏以 ⭐ 置顶显示）
3. 参考图（可选 → img2img 派生）：点「📁 选图」从本地选文件上传（自动存入输出目录 `参考图/` 子文件夹，显示缩略图），或手填输出目录内已有的文件名
4. 点「生成 ⚡」，图自动存入输出目录并出现在画廊

## 三点五、提示词工坊（编辑 / 权重 / AI 协作）

不只是"中文翻译成英文"——完整的提示词加工台：

1. **导入**：手动粘贴，或从「最近一次生成 / 全局前缀 / 任务行」一键导入
2. **拆成标签编辑**：点「🧩 拆成标签编辑」把提示词拆成标签芯片——每个标签可：
   - `+` 增强（NAI 语法 `{tag}`，每层约 +5% 权重，可叠 3 层）
   - `−` 减弱（`[tag]`）
   - `✕` 删除
   - 输入框添加新标签（带联想）
   所有改动**实时写回源文本**，括号语法原样保留
3. **AI 协作**（走 NAI 自带文字模型）：
   - 🌐 中译英：中文描述 → danbooru 标签
   - ➕ 扩写：保持人设不变，补服装材质/光影/氛围细节
   - ✂ 瘦身：去冗余矛盾标签，收敛到核心
   - 🎨 按风格改写：更华丽 / 更简洁 / 更写实 / 更动漫，人物特征严格不变
4. **发送到**：结果可直接进快速生图卡片 / 角色锚点串 / 全局前缀 / 存为画师串收藏；「⤴ 结果作为新源」可继续迭代

典型迭代流：从最近生成导入 → 拆标签删掉不想要的 → AI 扩写 → 拆开微调权重 → 存收藏。

## 四、角色立绘批量（核心工作流）

以「古代中原士兵」为例：

1. 切到「🧙 角色立绘工坊」，点「+ 新建角色卡」
2. 填：
   - **角色名**：中原士兵；**文件夹**：士兵（可留空=角色名）
   - **人设锚点串**（不变特征）：`1boy, ancient chinese soldier, light armor, red tassel helmet, holding spear`（中文可先在提示词工坊「中译英」，再「发送到角色锚点串」）
   - **变体池**（每行一个变体）：
     - 正面：`standing at attention, front view, full body` × 3 张
     - 战斗：`combat stance, dynamic pose` × 3 张
     - 休息：`sitting, resting, campfire` × 2 张
   - **seed 策略**：想要同一张脸选「固定」；想要多样化选「随机」
3. 点「📐 展开到任务表」→ 自动生成 `士兵/中原士兵-正面-01.png` 这样的任务行
4. 「▶ 预检」看汇总（含 Anlas 预估）→「开始批量生成」
5. **同脸进阶**：批量跑完后，挑一张最满意的，在任务表给其他行填「参考图」= 那张的文件名（或点行内 📁 上传本地图）→ img2img 派生（默认强度 0.6），保持构图的同时换姿势
6. 中断/关机后再开，已生成的自动跳过（断点续跑）

### Anlas 预算保护

「高级」里可设预算上限（如 500）。批量前如果预估超限会拒绝启动；执行中每张实时累计，超限自动停。批量结束日志会对比真实 Anlas 变化。Opus 用户标准参数（28 步内、≤1024²、文生图）免费；img2img、超尺寸、超步数都收费——预估面板会告诉你哪些张免费。

## 五、✂ 去白边（立绘特化）

NAI 出图自带透明背景，但边缘常有一圈白边（半透明白色像素）。画廊上方设置：

- **边缘收缩**（默认 1）：裁掉轮廓外几像素——白边重就调到 2
- **alpha 阈值**（默认 24）：清理半透明噪点
- **去白色污染**（默认开）：把边缘颜色里混的白色减掉

单张：图卡上「✂ 去白边」；批量：「✂ 批量去白边」处理所有未处理的图，产出 `xxx_cut.png`（原图不动）。

**为什么不会把白尾巴/白袍/鼻尖阴影抠掉**：判定依据是透明度结构而非颜色。白边是"轮廓外的半透明窄环"，白袍白尾巴是"实心不透明区域"，鼻尖阴影在实心区内部——算法只动前者。若遇到极端图（纯白发贴纯白背景断裂），把收缩调到 2~3 再试。

## 六、画师串收藏库

试出好用的画师串/人设串后存在「🏷 画师串收藏库」：名称 + 串文本。之后：

- 提示词输入时输入名称片段，联想列表 ⭐ 置顶一键插入
- 或「插入全局前缀」对所有图生效

## 七、常见问题

- **测试连接 401/403**：令牌错误或被撤销，重新生成
- **生成报 HTTP 402**：Anlas 不足
- **生成报 HTTP 429**：请求太频繁，把「请求间隔」调大（默认 3000ms）
- **V5 报 400**：V5 刚发布（2026-08-21），payload 若有字段出入属预期，把日志发给维护者按抓包修正（见 README 真机验证清单）
- **订阅面板 Anlas 显示"字段待真机确认"**：首次连接后把 `测试连接` 的返回内容反馈给维护者，一次修正字段映射
- **图片打不开**：检查输出目录是否被移动/重命名
